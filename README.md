# СМП Навигатор — восстановленный исходный проект

Версия: **1.2.0 BETA**

Это первая нормальная файловая версия проекта, восстановленная из опубликованной Mini App и текущего состояния разработки.

## Что уже работает

- Главная страница с 8 самостоятельными карточками протоколов.
- Активные карточки: **STEMI**, **ОКСбпST**, ишемический инсульт / ТИА, геморрагический инсульт, преэклампсия / эклампсия, мочекаменная болезнь / почечная колика и гипотермия / холодовая травма. Карточка ЖКК пока остаётся заглушкой.
- Карточка ОКСбпST по KR_154_4: диагностика, лечение и тактика со ссылками на страницы КР.
- Пять новых карточек BETA с вкладками диагностики, лечения и тактики.
- Вкладки: **Диагностика / Лечение / Тактика**.
- Режимы **Кратко / Подробно**.
- Светлая/тёмная тема.
- Избранное.
- Раздел препаратов с поиском.
- Адаптация под Telegram Mini App.
- Выбор стратегии: первичное ЧКВ / догоспитальная ТЛТ / отсутствие реперфузии.
- Тенектеплаза, альтеплаза, эноксапарин и НФГ по КР157_5.
- Чек-лист заполнения карты вызова.

## Медицинский источник для STEMI

Клинические рекомендации:
**«Острый инфаркт миокарда с подъемом сегмента ST электрокардиограммы»**, 2024, КР157_5.

Ключевые места:
- диагностика и ЭКГ: раздел 2.4;
- обезболивание/морфин/диазепам: раздел 3.2.1;
- кислород: 3.2.2;
- нитраты: 3.2.4;
- реперфузия: 3.1;
- дозировки: Приложение А3;
- догоспитальный алгоритм: Приложение Б4, стр. 210–211.

## Запуск

Самый простой вариант:

```bash
python3 -m http.server 8080
```

Открыть:

```text
http://localhost:8080
```

## Структура

- `index.html` — оболочка.
- `assets/styles.css` — дизайн.
- `assets/data.js` — данные/список протоколов/препаратов.
- `assets/card-content.js` — медицинский текст пяти дополнительных карточек BETA.
- `assets/app.js` — логика интерфейса.

## Важно

Это тестовая версия для клинической проверки. Она не заменяет локальные СОП, приказы, инструкции по применению препаратов и клиническое решение медицинского работника.
